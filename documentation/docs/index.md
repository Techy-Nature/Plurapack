# A shared voice, without giving up identity

**Plurapack** is a self-hosted member/headmate proxy for [Stoat](https://stoat.chat). It lets members of a plural system send messages with their own name, avatar, color, and proxy tag while preserving a stable identity behind the scenes.

Plurapack welcomes systems of every origin, as well as people who are questioning. It does not ask for an origin, diagnosis, or proof. It is a communication tool—not a diagnostic service.

## What Plurapack can do

- Keep stable system, member, and form IDs even when display names change.
- Proxy text using member-specific prefixes and optional suffixes.
- Give members aliases and alternate forms.
- Share one system between multiple authorized Stoat accounts.
- Import from PluralKit, Tupperbox, or another Plurapack installation.
- Export portable member metadata for backups.
- Optionally attach generated speech through an operator-managed Chatterbox server.
